## 关键发现

### 发现 1：Codex 能准确点击"专辑"标签

**引用**：
> "搜索结果已经返回，默认是'歌曲'。我会切到'专辑'页读取周杰伦专辑列表。"
> "已在 QQMusic 中点击"
> "已切到'专辑'，正在等结果刷新。"

**这意味着**：
1. Codex 能识别当前激活的标签是"歌曲"
2. Codex 能找到并点击"专辑"标签
3. Codex 能确认切换成功

**我们缺少什么**：
- ❌ 无法识别当前激活的标签 → 需要 `AXSelected` 属性
- ❌ 无法区分"歌曲"和"专辑"标签 → 需要更好的元素识别

### 发现 2：Codex 能从 AX tree 读取日期

**引用**：
> "QQ 音乐专辑页已经显示关键结果：最伟大的作品 标注 2022-07-15，同时也有一个更近的专辑项 太阳之子 标注 2026-03-25"

**这意味着**：
- 专辑列表中的每一项包含了日期信息
- Codex 从 AX tree 中读取到了这些日期
- **不是从截图识别的！**

**我们缺少什么**：
- ❌ 我们的 AX tree 中没有看到日期信息
- 可能原因：
  1. 我们的元素过滤丢失了包含日期的子元素
  2. 日期在 `AXValue` 或 `AXDescription` 中，我们没提取
  3. 日期是某个 `AXStaticText` 子元素，我们没有返回层级结构

## 核心问题：我们为什么找不到日期？

### 假设 1：日期在子元素中

专辑列表项可能的 AX 结构：
```
AXGroup (专辑项)
├── AXStaticText: "太阳之子"
├── AXStaticText: "周杰伦"
└── AXStaticText: "2026-03-25"  ← 这个我们可能没提取
```

我们当前只提取了：
```json
{
  "role": "AXStaticText",
  "name": "专辑："
}
```

但没有提取它的：
- 父元素（专辑项容器）
- 兄弟元素（日期文本）

### 假设 2：日期在 AXValue 中

```
AXGroup (专辑项)
├── AXTitle: "太阳之子"
├── AXValue: "2026-03-25"  ← 我们没提取 AXValue
```

### 假设 3：我们的过滤太激进

```swift
// 我们当前的过滤
.filter((el) => {
  const width = el.metadata?.frame?.width
  return width > 50 && el.name  // 日期文本可能 width < 50
})
```

## 立即需要做的改进

### 优先级 P0（立即实现）

1. **提取 AXSelected 属性**
   ```swift
   result["selected"] = getAttribute(element, kAXSelectedAttribute)
   ```
   - 用于识别当前激活的标签

2. **提取 AXValue 属性**
   ```swift
   result["value"] = getAttribute(element, kAXValueAttribute)
   ```
   - 日期可能在这里

3. **返回层级树结构（children）**
   ```swift
   result["children"] = getChildren(element).map { extractElement($0) }
   ```
   - 日期可能是子元素

4. **不要过度过滤**
   ```typescript
   // 不要丢弃小元素
   // 保留所有有 name 或 value 的元素
   ```

5. **添加滚动能力**
   ```swift
   // 方案 1: AX scroll action
   AXUIElementPerformAction(element, kAXScrollDownPageAction)
   
   // 方案 2: 键盘 Page Down
   CGEventPost(kCGHIDEventTap, keyDownEvent)
   
   // 方案 3: 拖拽滚动条
   ```
